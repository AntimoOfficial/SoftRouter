# 兼容性与验证范围

版本：0.1.0-alpha.1，开发预览。

| 项目 | 证据范围 |
| --- | --- |
| 专用部署 | Apple M1、macOS 14.8.5、独立 USB 以太网、小米 AX3000T 下游曾有真实客户端成功记录 |
| 专用部署 DHCP | 网关运行中从无地址重新获取上游 DHCP，单播 OFFER/ACK 成功且进程持续运行 |
| 专用部署 DNS | 使用上游校园 DNS 后，部分校内站点由不可达恢复；代理与直连分别核对 |
| 专用部署合盖 | 在已有全局禁睡设置、持续接电的特定机器上做过约一分钟下游实测；不是默认支持承诺 |
| 此通用源码包 | 配置、PF 规则构造、IPv6 模式与恢复、PF 边界、上游观测的离线回归；未做真实安装验收 |
| 其他 macOS、芯片、网卡和路由器 | 未验证；严格预检可能拒绝与已知 PF 结构不同的系统 |

核心使用 macOS 自带 Bash 3.2 和系统网络工具，不依赖 Hammerspoon、Python 或代理程序。Python 3 是开发时的发布检查依赖。当前配置限制见安装 README，包括 ASCII 服务名称、en 编号接口和同一 /24 的两个私有地址。

仅提供 IPv4 转发。Wi-Fi 认证、路由器私有管理 API、客户端代理、睡眠与物理接线不是转发核心可以完全接管的事项。出口按接口限制，未按 SSID 隔离；同接口误连自己的下游网络会产生错误路径。

USB 网卡移除或资源归属变化可能触发保护性停止及 ATTENTION；不承诺重新插回后自动接管不明状态。当前安装器支持首次安装，尚无自动升级或从个人旧部署迁移功能。

曾在专用试验期间出现系统崩溃；现有证据不足以确认根因或将其归因于本包。通用版本没有跨夜运行或重启验收记录。任何兼容性扩大都应附具体提交和实际测试记录。
