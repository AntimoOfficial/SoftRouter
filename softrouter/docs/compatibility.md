# 兼容性与验证范围

版本：0.1.0-alpha.5，实验版本。

新增 Windows ICS 与 Linux NetworkManager 测试版，提供安装和共享控制入口，尚未做真实联网、断线恢复、重启或卸载验收。其后端、子网与恢复语义不同于 macOS；macOS 的实测不适用于这两端，见 [平台指南](platforms.md)。

`0.1.0-alpha.4` 新增期望 Wi-Fi 诊断，旧 `0.1.0-alpha.3` 安装包不包含该字段或选项。应用更新不会自动升级已有网关。

| 项目 | 证据范围 |
| --- | --- |
| 专用部署 | Apple M1、macOS 14.8.5、独立 USB 以太网、小米 AX3000T 下游曾有真实客户端成功记录 |
| 专用部署 DHCP | 网关运行中从无地址重新获取上游 DHCP，单播 OFFER/ACK 成功且进程持续运行 |
| 专用部署 DNS | 使用上游校园 DNS 后，部分校内站点由不可达恢复；代理与直连分别核对 |
| 专用部署合盖 | 在已有全局禁睡设置、持续接电的特定机器上做过约一分钟下游实测；不是默认支持承诺 |
| 此通用源码包 | 配置、PF 规则构造、IPv6 模式与恢复、PF 边界、上游观测的离线回归；未做真实安装验收 |
| 只读诊断 | 旧状态、进程失配、超时、事件脱敏与输出的离线回归；已有专用部署上完成非特权只读采集，未改变网关 |
| 自动加入防误连 | 专用部署已在系统设置关闭下游 Wi-Fi 自动加入、保留目标上游开启，并重新进入设置核验；现网检查正常，未重演上游掉线 |
| 期望 Wi-Fi 诊断 | 已有专用部署上只读比对匹配；该结果不证明自动加入开关正确，也不承诺认证和切网自动恢复 |
| 电源与合盖诊断 | 合成测试验证供电、全局禁睡、矛盾/缺失证据和机盖状态解析；不改电源，不将闲置睡眠设置解释为合盖兼容性 |
| 图形安装包 | macOS 14+ 的 arm64 / x86_64 双架构构建、应用自测与包内容审计；未签名公证，未完成全新机器端到端安装 |
| 其他 macOS、芯片、网卡和路由器 | 未验证；严格预检可能拒绝与已知 PF 结构不同的系统 |

macOS 核心使用系统自带 Bash 3.2 和网络工具，不依赖 Hammerspoon、Python 或代理程序。Python 3 是开发时的发布检查依赖，也是 Linux 测试版的应用运行时；Windows 使用系统 PowerShell。macOS 配置限制见安装 README，包括 ASCII 服务名称、en 编号接口和同一 /24 的两个私有地址。

以下网络与恢复细节描述 macOS PF 实现。它仅提供 IPv4 转发。Wi-Fi 认证、路由器私有管理 API、客户端代理、睡眠与物理接线不是转发核心可以完全接管的事项。出口按接口限制，未按 SSID 隔离；同接口误连自己的下游网络会产生错误路径。

防误连采用 macOS 的逐网络自动加入设置：部署时关闭下游自动加入并核验，保留上游自动加入和双方凭据。网关核心不修改该设置，不增加自动切网服务；诊断 SSID 的权限与可见性随系统环境而异，无法取得时报告 unknown。

USB 网卡移除或资源归属变化可能触发保护性停止及 ATTENTION；不承诺重新插回后自动接管不明状态。当前安装器支持首次安装，尚无自动升级或从个人旧部署迁移功能。

曾在专用试验期间出现系统崩溃；现有证据不足以确认根因或将其归因于本包。通用版本没有跨夜运行或重启验收记录。任何兼容性扩大都应附具体提交和实际测试记录。
