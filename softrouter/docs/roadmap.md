# 实现状态与计划

## 当前仓库

- 参数化配置、首次安装、launchd 常驻、状态查询、启动、停止及卸载。
- 上游断线仅观测，保留转发；DHCP 单播回复本地接收并禁止转发。
- IPv6 未初始化处理、PF 所有权检查及精确清理。
- 内置只读 diagnose 程序、Markdown/JSON 报告、图形诊断按钮和网络巡检 Skill；检查有超时限制。
- AI 部署手册、路由器/DNS/代理/电源说明。
- 双击 `.pkg` 安装图形应用，导入由 AI 准备的配置后通过系统授权安装网关；尚未签名公证。
- 离线回归、发布文件白名单、暂存区与提交扫描、从提交生成源码包。

## 尚未实现

- 统一 inspect/plan/apply CLI、持续 JSON 状态与自动环境规划。
- 自动升级、版本回退及旧个人部署迁移。
- 路由器 API 自动配置、客户端代理配置适配器。
- USB 热插拔自愈、按上游网络身份约束转发。
- 通用安装版的实机安装、重启和跨夜验收。

实现顺序以可验证的恢复能力为先。任何新工具先说明计划修改什么、如何验证和恢复，再执行特权操作。兼容性声明由实际证据扩展。
