# 通用路由器设置

拓扑：Mac Wi-Fi 上游 → 独立以太网 → 路由器 WAN → LAN/Wi-Fi 客户端。

先保留能打开管理页的 LAN 或 Wi-Fi 连接。不要在 Mac 下游以太网服务仍启用 DHCP 时将其接到路由器 LAN，否则可能改变 Mac 的默认出口。

根据已经生成的本机配置填写以下字段：

| 路由器 WAN 字段 | 来源 |
| --- | --- |
| 上网方式 | 静态 IPv4 |
| IP 地址 | CLIENT_ADDRESS |
| 子网掩码 | 255.255.255.0 |
| 默认网关 | GATEWAY_ADDRESS |
| 首选、备用 DNS | 当前上游实际可用的解析器 |

路由器 LAN 必须与 WAN、上游以及已有本地路由不冲突。保留路由器的 LAN DHCP 与 NAT，由它为客户端分配地址。WAN/LAN 自适应型号需要核对或固定实际 WAN 端口，不能只凭端口外观判断。

完成 Mac 端安装并确认 RUNNING 后，接到已经核对的 WAN 端口。验证客户端的默认网关属于路由器 LAN、能解析目标域名并打开真实页面。部分路由器禁用 WAN 侧管理和 ping，不能据此认定 WAN 联网失败。

不要未经用户授权重置路由器、升级固件、创建无线密码或暴露 WAN 管理功能。配置后留下字段记录，凭据保持在用户本地。
