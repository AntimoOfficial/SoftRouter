# 排障顺序

先读取 gatewayctl status，明确是否为本通用包的安装。不要将旧个人部署的命令与此包混用。

| 现象 | 先检查 | 处理边界 |
| --- | --- | --- |
| RUNNING 但都打不开 | 上游认证、地址、默认出口；下游 WAN 参数 | 上游离线不重启网关；等待认证/链路恢复 |
| Mac 正常，下游全部失败 | WAN 接线、静态地址、客户端默认路由、转发证据 | Mac curl 成功不是转发成功的证据 |
| 只有部分校园域名失败 | 两端 DNS、路由器 DNS、浏览器及代理的独立解析 | 参照 dns-and-proxy.md，避免盲目重启 |
| 保存代理配置后仍旧失败 | 当前运行核心实际规则、DNS 和缓存 | 不仅检查磁盘文件 |
| HTTP 200 但页面异常 | 正确应用路径、正文、跳转及必要公开资源 | 不把错误页计为应用验收通过 |
| 预检拒绝 PF | 已有引用、规则、状态或其他管理者 | 不全局清空或关闭 PF |
| ATTENTION | 私有恢复状态、资源所有权、退出原因 | 不删除锁后强行启动，不重置第三方资源 |
| 重启后失败 | 版本兼容性、服务/硬件绑定、ND6 初始状态 | 未初始化 IPv6 与已启用但 flags 为零不同 |
| USB 网卡拔插后失败 | 原网卡是否回来、服务身份、保护锁 | 当前不承诺热插拔自动恢复 |
| 合盖后失败 | 实际系统睡眠、USB 链路、电源 | 参照 power-and-lid.md，不默认全局禁睡 |

诊断只采集当前问题需要的信息，保留在本机。公开问题按 privacy.md 脱敏；密码、订阅和整份网络偏好不是必要的报告材料。
