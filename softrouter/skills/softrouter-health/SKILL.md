# SoftRouter 网络巡检

读取仓库中的 `softrouter/docs/diagnostics.md`，使用 `/bin/bash softrouter/diagnose.sh`；新安装的网关也可用 `/Library/SoftRouter/gatewayctl diagnose`。人类可在图形应用中生成报告并阅读 report.md，AI 读取同次生成的 report.json；schema_version 为 1，新版 history_summary 可选，兼容旧报告。默认回看三天，CLI 支持 --days 1 至 7，先检查 --help。无需额外运行时 API、后台监控或 Skill 专用依赖。Skill 文件被复制到其他目录后，先定位用户的 SoftRouter 仓库或已安装入口，不假设相对路径仍可用。命令不存在时明确缺少该版本，不编造接口。

先确定本机实际部署与用户要看的时间范围。保持现网，使用非特权入口；旧部署可以显式传 --label 与 --log-dir。核对后填写接口，不套用学校 IP、主机名、MAC、网卡编号或历史个人路径。

已核对预期上游 Wi-Fi 时，可显式传 --expected-ssid；该选项从 0.1.0-alpha.4 开始提供，先检查当前入口的 --help，不假定旧网关已随应用升级。错配是 attention，无权限或无法识别是 unknown，不记录 SSID 原文；不指定则不新增采集。此项不检查自动加入开关，也不会自动切网。

按请求选取至多五个真实公开入口，传 --url；已知本机 HTTP 代理且需比较时传 --proxy。网站登录页可以只读检查，不提交登录。不要把密码、订阅 URL、带凭据或查询参数的链接放进命令。没有网站目标时，报告明确只验证本机状态。

运行后读取 report.json 与 report.md。关注下列易误判处：

- 磁盘 RUNNING 要与启动会话、launchd PID、守护/转发进程及转发开关交叉核对；状态更新时间不是心跳。
- observed 表示取得结果，不是全网健康；unknown、超时、空日志和缺少权限不能变成正常。
- 进程持续运行不等于互联网持续在线；网卡错误计数不等于丢包率；不凭快照计算在线率。
- 同一 Wi-Fi 接口可能误连自身下游。当前 SSID 与预期错配时核对默认路由和系统自动加入设置；若获准修复，按部署手册关闭下游自动加入、保留目标上游开启，保存后重新打开核验，保留凭据。不用重启网关或循环切网，设置核验不等于掉线重演。
- 历史漫游、EAP 成功与 DHCP BOUND 可以支持自动恢复，但事件间隔不是实测中断时长，也不证明认证失败根因已解决。
- 新报告的 history_summary 单独汇总可见历史异常与截断状态；attention_count 只表示当前事实，不代表近期零异常。列表保留最近 300 条，摘要计数覆盖本次取得的全部去重记录；检索失败、超时或日志留存不足时，不将计数解释为整个时间窗的完整统计。旧报告缺少摘要字段时保留未确认。
- HTTP 200 可能是错误页。对用户实际故障核对正确路径与公开内容；程序没有验收登录与全部子资源。
- 本机代理不自动覆盖路由器下游。需要下游证据时询问真实客户端结果，排除蜂窝兜底；无权限或用户暂停的设备保持未验证。

人工要求近期软件或运行总结时，同时按 diagnostics.md 的「人工近期汇报」核查 GitHub；单个具体联网故障不额外扩展为项目审计。使用可用连接器或已有认证的 gh CLI，凭据保留本地：

- 比较远端默认分支与本地 HEAD，单列公开源码的 dirty 状态、最新 Release/标签和准确提交的 push CI；HEAD 相同不代表未提交优化已发布。
- 报告最近 14 天 views、uniques、clones、unique cloners，以及实际返回日期桶、UTC 时区和缺失日期；可读时补充来源、热门路径。接口或权限不可用记为 unknown，不强制登录，不补零。
- 核查 Stars 并辨别所有者或已知维护者本人、Forks、Watchers（subscribers_count）；全部状态的 Issues/PR、Issue/PR 讨论与评审、提交评论及可读的 Discussions；分开汇总安装资产、源码的累计下载，有同一资产 ID 基准时比较变化。
- 访问、clone 与下载不能换算成安装用户或独立社区验证；不同滚动窗口不能直接相减。有先前人工汇报时注明基准日期与来源，不创建监控状态文件。没有公开反馈不等于没有故障。附查询时间及 GitHub 证据链接，保留统计和验证缺口。

报告应给出明确时间窗、当前状态、历史事件及尚未验证项，附本地报告链接。补充检查只针对未解决的问题，限制耗时，不重复跑全库日志统计。任何网络修复都不属于本 Skill 的默认行为；用户明确要求修复后再按实际授权处理。报告保留本地，分享前脱敏，不自动上传或修改开源仓库。
