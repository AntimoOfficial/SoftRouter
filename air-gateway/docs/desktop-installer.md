# 双击安装预览版

从 [Releases](https://github.com/AntimoOfficial/air-gateway/releases) 下载 `Air-Gateway-0.1.0-alpha.2-unsigned.pkg`。这是包含 Apple Silicon 与 Intel 架构的 macOS 14+ 安装包，运行时不需要 Git、Python、Xcode 或终端脚本。

## 安装流程

1. 双击 `.pkg`，使用 macOS 安装器把 Air Gateway 安装到「应用程序」文件夹。
2. 把仓库地址交给能操作目标 Mac 的 AI，让它阅读 [AI 部署手册](ai-setup.md)，核对闲置下游接口、准备网络服务并生成 `gateway.conf`。
3. 打开「应用程序 → Air Gateway」，点击「导入配置文件」，核对显示的网卡和地址。
4. 保持上游 Wi-Fi，拔下下游网线，点击「安装网关」，在系统授权提示中输入管理员密码。
5. 状态为 RUNNING 后，将下游网线接到路由器 WAN，配置 WAN、网关和上游 DNS，再从下游设备验证网页。

应用安装与网关启用是两个不同步骤。`.pkg` 只写入应用，不运行安装后脚本、不改变网络。应用导入配置不会立即改变网络，只有确认安装并完成系统授权后才调用严格预检的安装器。

当前是最小图形入口，没有自动发现向导或自动迁移。下游服务仍须按部署手册准备好；已有网关或 PF 占用会被拒绝。校园认证、路由器设置和合盖不由安装按钮自动完成。用户通过本机系统提示授权，应用不读取或保存密码。

## 签名状态

此预发布包没有 Apple Developer ID 签名或 Apple 公证。内置应用只带构建所需的 ad-hoc 完整性签名，不能证明发行者身份。首次打开可能被 Gatekeeper 阻止。

是否信任并打开由用户自行决定；参见 [Apple 的官方说明](https://support.apple.com/en-us/102445)。项目不提供关闭 Gatekeeper、删除隔离属性或绕过组织安全策略的脚本。要提供标准签名与公证的分发体验，仍需发行者的 Developer ID 证书及公证凭据。

## 验证范围

构建检查包含两个架构的编译、配置导入与转义自测、包内容展开审计、签名完整性检查以及原有离线回归。包中没有个人配置或管理员凭据。检查不会在开发机器上安装应用或启用另一套网关。

本预览仍没有在全新机器完成从下载、Gatekeeper、管理员授权到实际下游联网的完整验收；不能把构建通过当作该验收已完成。

停止和卸载网关使用 [现有控制命令](../README.md#安装与使用)。移除应用本身不会停止已经安装的常驻网关，须先停止并卸载网关。日志仍按隐私说明保留。

## 从源码构建

需要 macOS Command Line Tools 和 Python 3；用户安装 Release 不需要这些工具。在仓库根目录运行：

```sh
/bin/bash air-gateway/tools/build-macos.sh
```

默认从已审计的 HEAD 提交构建。开发时可使用 `--worktree`，构建信息会标记为未提交预览，不能把它冒充某个已发布提交。产物写入忽略的 `dist/`；不要将二进制加入 Git。
