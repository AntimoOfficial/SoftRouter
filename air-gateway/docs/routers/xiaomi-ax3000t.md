# 小米 AX3000T

已有专用部署使用 AX3000T RD03v2、原厂固件 2.0.28，按 generic.md 的静态 WAN 方案工作。其他固件界面与端口顺序需重新核对。

1. 从 LAN 或小米 Wi-Fi 进入管理页，完成用户自己的登录或初始设置。管理地址以实际 LAN 网关为准。
2. 在端口设置中识别连接位置。若选择固定 WAN，确保不是唯一的当前管理连接。专用试验使用过 LAN4 固定 WAN，但这不是所有设备可直接套用的编号。
3. 上网设置选择静态 IP，填写生成的 WAN 地址、掩码、网关与当前上游 DNS。
4. 保存后等待连接和解析恢复，再按通用指南验收。截图字段正确仍不等于下游已经通过。

本项目尚无路由器 API 适配器。AI 可按实际网页与工具权限协助操作，不能猜测管理 token 或调用未验证的私有接口。密码由用户自行输入。
