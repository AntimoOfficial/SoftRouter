# 隐私与问题报告

Air Gateway 不要求、读取或保存 Wi-Fi 与企业 802.1X 密码，不负责登录认证，也不包含遥测或向第三方上传诊断的功能。认证由 macOS 管理。

配置文件包含接口名称、下游服务名称及 UUID、MAC 地址和私有 IPv4 地址。这些内容不是认证凭据，但可以识别设备和网络环境，不应原样提交到公开仓库。

上游诊断可能记录 SSID、IPv4 地址与默认网关；运行日志还可能包含时间、PID、系统启动标识、接口信息、PF 引用及错误。PF 连接状态另含通信地址与端口，不应视为匿名信息。

| 位置 | 内容 |
|---|---|
| `/Library/AirGateway` | 安装程序与本机配置 |
| `/Library/Logs/AirGateway` | 状态、运行日志与归档诊断 |
| `/private/var/run/air-gateway` | 受保护的本轮状态、所有权记录与清理依据 |

卸载保留日志；不要将卸载等同于删除全部本地诊断。异常状态仍存在时，不要为清理隐私资料而直接删除正在使用的恢复目录。

公开问题报告应只保留复现所需的系统版本、硬件类别、操作顺序、状态值及脱敏错误片段。统一替换用户名、绝对个人路径、服务 UUID、MAC、SSID、实际地址、时间线标识及 PF 引用。无需提交完整网络偏好、整份配置、数据包抓取或历史日志。

README 中的设备与地址示例仅说明格式，不来自原部署。本仓库不保存原部署的认证信息、私有配置或历史运行证据。
