# Changelog

## 0.1.0-alpha.2

- 增加可双击的 macOS `.pkg`：仅安装配置应用，网关由用户导入配置并明确授权后安装。
- 提供 Apple Silicon / Intel 通用图形入口、配置预览、系统管理员授权和只读状态查询。
- 将用户确认的配置冻结并核对摘要，再调用原安装器；保持已有网关拒绝覆盖的行为。
- 增加应用自测、安装包展开审计及构建脚本。包未使用 Developer ID 签名或 Apple 公证，完整实机部署仍待验证。

## 0.1.0-alpha.1

- 补入上游 DHCP 单播回复接收及禁止转发保护，覆盖正常与清理规则。
- 增加 AI 部署、路由器、DNS/代理、电源和故障处理说明。
- 增加离线守护逻辑回归、发布白名单与从 Git 提交打包的工具。

- 将 Wi-Fi 上游到独立以太网下游的 IPv4 NAT 部署整理为实验性项目。
- 以 launchd 管理进程，保留网络断开期间的转发配置。
- 通过严格数据配置替换机器专属网卡、服务 UUID、MAC 和地址。
- 保留独立 guardian、资源所有权核验、启动预检和精确清理。
- 处理重启后下游 IPv6 未初始化的情况，避免误判后反复退出。
- 提供安装、停止、卸载、离线回归测试及故障状态说明。

该版本是开源准备版；泛化后的安装路径尚未经真实部署验证。
